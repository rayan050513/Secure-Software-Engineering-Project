

Secure Student Information System (SSIS) - Java Implementation

Project Overview:
This project is a Secure Student Information System developed for the Secure Software Engineering course at Prince Mohammad Bin Fahd University. The system focuses on the secure management of student grades, ensuring high levels of Confidentiality, Integrity, and Availability as per course requirements.

The primary focus of this repository is the Secure Login Process, demonstrating defensive coding techniques against common web vulnerabilities.

1.Security Features:
- SQL Injection Prevention:Utilizes java.sql.PreparedStatement to neutralize injection attacks.
- Secure Hashing: Implements the BCrypt algorithm for password hashing and salting.
- Input Validation: Strict allow-list validation for all user-provided data.
- Role-Based Access Control: specific permissions for Student and Instructor roles.

2.Tech Stack:
- Language used: Java
- Database: MySQL / PostgreSQL
- Security Library: jBCrypt
- Version Control: GitHub

3.Starting the website
1. Download the frontend and backend from GitHub.
2. Database Setup: Import the provided schema to your local SQL server.
3. Run: Open the project in IntelliJ or Antigravity and run Main.java to start the local host.
